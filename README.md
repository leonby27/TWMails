# TWMails — велком-цепочка Timeweb (оплата на 1 месяц)

HTML-письма велком-цепочки и просмотрщик.

**Просмотр:** https://leonby27.github.io/TWMails/

## Содержимое
- `index.html` — просмотрщик: сайдбар со списком писем + iframe.
- `letter-1.html` — Хороший старт!
- `letter-3.html` — Запускаем ваш сайт вместе
- `letter-4.html` — Пара слов лично от меня
- `letter-5.html` — Давайте посчитаем выгоду?
- `letter-6.html` — Любите промокоды?
- `EMAIL_RULES.md` — свод правил вёрстки/стиля писем.
- `templates/base-email.html` — исходный каркас.

> Письмо 2 пропущено («в процессе согласования»).

## Перед боевой отправкой
- Проставить реальные ссылки (сейчас `href=""`).
- Вставить фото в письме 4.
- Залить картинки/иконки на CDN, заменить inline-SVG на `<img>` с URL (Gmail/Outlook режут SVG).
- Подготовить plain-text версии.
